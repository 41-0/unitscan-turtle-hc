# Changelog

## 1.3.9

- Shortened the alert button label to Snooze.

## 1.3.8

- Added configurable per-mob alert snoozing and compact alert buttons.

## 1.3.7

- Made the settings window draggable by its title and saved its position.

## 1.3.6

- Set the minimap button radius to 78 UI units and shifted the icon left by 2 UI units.

## 1.3.5

- Matched the minimap button radius to HCDeaths (80 UI units).

## 1.3.4

- Aligned the minimap button with the rim and added a saved drag position.

## 1.3.3

- Added slash commands to enable, disable, or toggle scanning with chat confirmation.

## 1.3.2

- Added a saved toggle for warning sound playback.

## 1.3.1

- Removed the three bundled warning sounds. The default uses the game client’s RaidWarning sound.

## 1.3.0

- Added a minimap button. Left-click toggles settings and right-click toggles global scanning.
- Synchronized scanning state between the minimap button and the settings window.

## 1.2.0

- Increased the default minimum alert duration to 10 seconds.
- Enabled scanning during combat by default and added an option to pause it.
- Added simultaneous alert plates with individual timers and an optional model for the newest plate.

## 1.1.0

- Added settings for scanning, the sound path, alert scale, screen flash, and the minimum alert duration.
- Added automatic dismissal and a persistent ignored-mob list.
